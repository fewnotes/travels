# personal-sites

Interactive "places visited" maps (US/Canada states & provinces, and world
countries), built as static HTML/CSS/JS for GitHub Pages.

## Finding a region's id (for STATE_VISITED_IDS etc. in assets/js/data-*.js)

`assets/data/region-index.json` lists every state/province and country id
next to its name, sorted alphabetically by name — search it for the place
you want to add. It's generated by the same script that builds the
boundary data (below), so it's always in sync with what the map actually
uses.

## Regenerating map boundary data

`assets/data/us-canada.geojson`, `assets/data/world-countries.geojson`, and
`assets/data/region-index.json` are static snapshots, generated once and
committed to the repo. The map only ever reads the two `.geojson` files at
runtime — it does not fetch or check the original data sources
(`us-atlas`, `world-atlas`, `click_that_hood`) live, so upstream boundary
corrections or updates will not reach the site automatically.

To pick up upstream changes, regenerate the files:

```sh
cd scripts
npm install
npm run generate
```

This overwrites all three files in `assets/data/`. Review the diff, then
commit it if it looks right:

```sh
git diff --stat assets/data/
git add assets/data/
git commit -m "Regenerate map boundary data"
```

See `scripts/generate-geodata.js` for exactly what each dataset includes
and excludes (e.g. dropped uninhabited territories, Kosovo/Somaliland/N.
Cyprus fallback codes).
